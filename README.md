# JIC 2027 — Research Explorer (versión 2)

Diseño responsive, sin emojis: iconografía vectorial SVG, tipografía Manrope/DM Sans y paleta azul/cobalto sobre blanco cálido. Cinco propuestas científicas explorables y tabla comparativa.

## Publicar actualización en GitHub Pages
1. Descomprime el archivo ZIP.
2. En el repositorio `Ideas-JIC`, reemplaza `index.html`, `styles.css`, `script.js` y `README.md` en la raíz del repositorio (usa Add file → Upload files y confirma la sustitución).
3. Confirma con **Commit changes**.
4. GitHub Pages se actualiza automáticamente desde `main` / `(root)`; no necesitas crear otro repositorio.
5. Abre la dirección que aparece en Settings → Pages y actualiza la página (en iPhone también puedes abrir en pestaña privada si ves una versión antigua).

Sin frameworks ni compilación.
